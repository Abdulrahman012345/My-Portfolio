# Abdul Rahman N - Portfolio

## Files
- `index.html` - HTML page structure and external library imports
- `style.css` - extracted portfolio CSS
- `script.js` - extracted portfolio JavaScript and React components

## Run
Open `index.html` in a browser. For local development, you can also use VS Code Live Server.

The page loads React, ReactDOM, HTM, Three.js, and Tailwind CSS from the CDN URLs already present in `index.html`, so an internet connection is required for those libraries.
